# 🍕 Pizza-on-Demand

A simple HTML-only pizza ordering form for a fictional restaurant called **Black Goose Bistro**. This form allows users to enter their personal information and customize a pizza order including crust type, toppings, and quantity.

---

## 📌 Features

- Clean, form-based UI to capture customer data.
- Background image for visual appeal.
- Crust selection (radio buttons — one choice only).
- Multiple toppings selection (checkboxes).
- Quantity input using number field.
- Submit and Reset buttons.

---

## 💻 Technologies Used

- HTML5
- Inline CSS (for background styling)
- No JavaScript or backend required
- No frameworks (Bootstrap optional if you want to style it later)
